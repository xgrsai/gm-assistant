# AI GameMaster

AI-powered RPG game master built with React and Django.

## Features

- AI chat interface
- RPG-style storytelling
- Persistent conversation history
- Markdown message rendering

## Tech Stack

Frontend:
- React
- Vite
- TailwindCSS

Backend:
- Django
- Django REST Framework

## Project Goal

Create an interactive AI game master experience for text-based RPG adventures.
